Bienvenido

Este sitio web permite consultar diferentes tours turísticos y realizar una reservación de forma sencilla.

El objetivo es facilitar a los turistas la elección de un tour y conocer el costo de su reservación.

Problema

Algunas personas tienen dificultades para encontrar información sobre tours turísticos y conocer rápidamente cuánto pagarían por su viaje.

También puede ser complicado organizar los datos de una reservación cuando se realiza de manera manual.

Solución tecnológica

Se propone un sistema web sencillo para consultar tours y realizar una reservación.

El sistema permite seleccionar un destino, indicar el número de personas y calcular automáticamente el precio total.

Información
